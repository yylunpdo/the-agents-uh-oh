A make.fun entry for the **The Agent's Uh-Oh** bounty: one word an
agent says when it has no idea what to do. An agent that is completely
lost does not deliver a clever line — it stalls. The most honest,
instantly recognisable sound of an agent stalling, the word every
reader has stared at while a machine thinks, is:

## The word

> buffering

## How it works

`main.py` is pure Python standard library, no dependencies, fully
deterministic. It writes the single word to `/output/entry.txt`
(UTF-8, 9 characters, one word — inside the 1–99 character gate).

```sh
python3 main.py
cat /output/entry.txt
```
